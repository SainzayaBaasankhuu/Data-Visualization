## Project 1: Interactive Visualization — Renewable Energy & Socioeconomic Development
**Tool:** Python (Google Colab)  
**Notebook:** `Interactive Visualization - Global Renewable Energy Adoption and Socioeconomic Development.ipynb`  
**Dataset:** [Loaded directly from GitHub using a raw link for full reproducibility ](https://raw.githubusercontent.com/SainzayaBaasankhuu/Data-Visualization/main/final_clean_merged_owid.xlsx
) 

This interactive notebook explores how renewable energy adoption relates to key socioeconomic indicators such as:

- GDP per capita  
- Life expectancy
- Energy mix composition  
- CO₂ emissions  
- Child mortality

The visualization allows users to interact with global data, compare countries, and observe long‑term trends.

## Project 2: Predicting the 2026 Grammy *Song of the Year*
**Tool:** Power BI  
**File:** `Power BI - Predicting song of the year of Grammy 2026.pbix`

This dashboard analyzes Billboard chart performance, streaming metrics, artist popularity, and historical Grammy trends to explore:

- Which songs are most likely to win **Song of the Year** at the 2026 Grammys  
- How chart performance correlates with Grammy outcomes  
- Artist momentum and genre patterns  

📊 *The dashboard includes:*  
- Trend analysis  
- Feature comparisons  
- Artist performance breakdowns  
- Predictive indicators
